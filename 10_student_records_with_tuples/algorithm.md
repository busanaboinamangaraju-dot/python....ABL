# Student Records Using Tuples

## Algorithm
1. Start and create an empty records list.
2. Repeat three times: read a student's roll number, name, and mark.
3. If the mark is below 0 or above 100, display an error and stop collecting records.
4. Otherwise, create a tuple containing roll number, name, and mark, then add it to the records list.
5. If three valid records were entered, display each student's details.
6. Stop.
