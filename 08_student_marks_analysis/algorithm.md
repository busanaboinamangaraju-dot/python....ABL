# Student Marks Analysis

## Algorithm
1. Start.
2. Read the number of subjects.
3. If the number is not positive, display an error.
4. Otherwise, read each subject mark and check that it is between 0 and 100.
5. If any mark is invalid, display an error and stop processing.
6. If all marks are valid, calculate the highest mark, lowest mark, and average.
7. Display the highest, lowest, and average marks.
8. Stop.
