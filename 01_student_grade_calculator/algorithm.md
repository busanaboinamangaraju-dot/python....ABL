# Student Grade Calculator

## Algorithm
1. Start.
2. Create an empty list to store marks.
3. Repeat five times: read a subject mark.
4. If a mark is below 0 or above 100, display an error and stop collecting marks.
5. If five valid marks were entered, calculate the total and percentage.
6. Assign a grade using the percentage ranges: A (90 or above), B (80–89.99), C (70–79.99), D (60–69.99), otherwise E.
7. Display total marks, percentage, and grade.
8. Stop.
