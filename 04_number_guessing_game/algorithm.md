# Number Guessing Game

## Algorithm
1. Start.
2. Set the secret number to 7, attempts to 0, and guess to a value different from 7.
3. Ask the user to guess a number between 1 and 10.
4. Read the guess and increase the attempt count by 1.
5. If the guess is smaller than 7, display “Too low!”.
6. If the guess is greater than 7, display “Too high!”.
7. Otherwise, display the success message and number of attempts.
8. Repeat steps 3–7 until the correct number is guessed.
9. Stop.
