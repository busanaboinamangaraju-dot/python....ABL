# Shopping Cart Bill

## Algorithm
1. Start and create empty item-name and price lists.
2. Repeat three times: read an item name and its price.
3. If a price is negative, display an error and stop collecting items.
4. Otherwise, add the item name and price to their lists.
5. If three valid items were entered, display each item with its price.
6. Add all prices to calculate the total.
7. Display the total bill.
8. Stop.
