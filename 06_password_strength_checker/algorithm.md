# Password Strength Checker

## Algorithm
1. Start.
2. Read a password.
3. Set the digit-found and uppercase-found flags to False.
4. Visit each character in the password.
5. If a character is a digit, set the digit-found flag to True.
6. If a character is uppercase, set the uppercase-found flag to True.
7. Check whether the password has at least 8 characters, a digit, and an uppercase letter.
8. Display that the password meets the basic rules if all conditions are true; otherwise display improvement guidance.
9. Stop.
