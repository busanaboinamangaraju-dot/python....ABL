# Duplicate Removal Using Sets

## Algorithm
1. Start.
2. Read a sequence of values separated by spaces and split it into a list.
3. Create an empty set named seen and an empty list named unique_values.
4. Visit each value in the input list.
5. If the value is not in seen, add it to seen and append it to unique_values.
6. Display the unique values in their original first-occurrence order.
7. Stop.
