## Running a project
1. Install Python 3.
2. Open a project folder in PyCharm or another Python editor.
3. Run `main.py` and enter the requested values.

Each project README describes the problem, objectives, assumptions, algorithm, flowchart, pseudocode, test cases, and conclusion. Run each program yourself, capture actual output screenshots, personalize this report, and prepare a consolidated PDF if required.
