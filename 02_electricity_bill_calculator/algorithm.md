# Electricity Bill Calculator

## Algorithm
1. Start.
2. Read the electricity units consumed.
3. If units are negative, display an invalid-units message.
4. Otherwise, if units are at most 100, calculate the bill at Rs. 1.50 per unit.
5. Otherwise, if units are at most 200, charge Rs. 1.50 for the first 100 units and Rs. 2.50 for the remaining units.
6. Otherwise, charge Rs. 1.50 for the first 100, Rs. 2.50 for the next 100, and Rs. 4.00 for units above 200.
7. Display the bill when the input is valid.
8. Stop.
