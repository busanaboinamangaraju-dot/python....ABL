# Simple ATM Simulation

## Algorithm
1. Start and set the initial balance to Rs. 1000.
2. Display the ATM menu.
3. Read the user's choice.
4. If the choice is 1, display the balance.
5. If the choice is 2, read a deposit amount; add it to the balance if it is positive, otherwise display an error.
6. If the choice is 3, read a withdrawal amount; reject non-positive amounts and amounts greater than the balance; otherwise subtract it from the balance.
7. If the choice is 4, display the exit message and finish.
8. For any other choice, display an invalid-choice message.
9. Repeat the menu until the user chooses 4.
10. Stop.
