# Student Attendance Calculator

## Algorithm
1. Start.
2. Read the total number of classes held and classes attended.
3. If total classes are not positive, attendance is negative, or attended classes exceed classes held, display invalid data.
4. Otherwise, calculate attendance percentage as (attended / held) × 100.
5. Display the attendance percentage.
6. If the percentage is at least 75, display that the student is eligible; otherwise display that attendance is below 75%.
7. Stop.
